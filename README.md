## House Price Prediction

A simple Machine Learning project that predicts house prices using **Linear Regression**.

## 📌 About the Project

This project uses house-related features such as area, number of bedrooms, bathrooms, etc. to predict the price of a house.

The model is trained using **Linear Regression** and the trained model is used in a **Streamlit web application**.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib
- Streamlit
- Jupyter Notebook
